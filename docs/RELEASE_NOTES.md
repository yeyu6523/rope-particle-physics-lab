# 绳索与粒子实验室 v1.0.1

修复绳索弹性过大：多子步长度约束、按时间换算的阻尼、基于连通绳长的拖拽范围限制，以及减少松手反弹的几何位移处理。

- 指定极限参数单端摆场景中，单段峰值拉伸从 118.95% 降为 1.30%；默认单端摆从 4.73% 降为 0.81%。
- 拖动中点超出双锚点可达范围时，停在绳长允许的边界；剪断后解除对应限制。
- 新增 6 项物理回归检查，共 21/21 通过；25/25 界面集成检查通过，并检查发布 exe 本体。
- 粒子功能和界面视觉样式保持原有设计；迭代滑块单位明确为“次/子步”。

具体测量场景、前后原始数据和误差范围见 `docs/ROPE_STIFFNESS.md`；版本校验见 `docs/verification/release-manifest.json`。

## v1.0.0

Windows x64 自包含单文件程序，下载 `PhysicsLab.exe` 后直接运行，不需要 Unity 或单独安装 .NET 运行时。

- 绳索：悬索桥、单端摆、自由落绳，拖拽节点与锚点、移动障碍物、右键剪断、实时参数调整。
- 粒子：喷泉、烟花、飘雪、旋涡，连续发射、寿命回收、拖尾、风场与点击爆发。
- 支持暂停、单步、重置、中文界面和保存画面。
- 已通过 15 项物理测试和 25 项界面集成检查，并对本次发布 exe 本体运行检查，退出码 0。

GitHub 仓库根目录包含未压缩的 `.sln`、`.csproj` 和 `.cs` 完整工程。源码不是压缩包或 unitypackage；Release 的单独 exe 是便于直接演示的成品。截图中的 0 FPS 来自暂停帧计时器的确定性捕获，不是帧率基准。

版本校验与范围说明见 `docs/VERIFICATION.md` 和 `docs/verification/release-manifest.json`。
