# 算法与代码对应

## 仿真时间

`MainForm.OnTick` 使用 `Stopwatch` 读取真实经过时间，累积后以 `dt = 1/120 s` 执行物理步进。单帧墙钟增量限制为 0.05 s，并限制追赶步数，避免窗口拖动或长时间阻塞后产生过大的积分步长。绘图与物理步长分离；后台不活动页面不继续推进，切换页面后保留该页状态。最小化时停止物理推进。

## 绳索：Verlet + 距离约束

实现：`src/PhysicsLab.Core/RopeSimulation.cs`。

节点保存当前位置 `x`、前一子步位置 `x_prev` 和固定锚点位置。从 v1.0.1 开始，每个外部物理步拆成多个子步，在更短时间内反复积分和投影，减少长绳张力传播不充分造成的拉伸。默认每个 1/120 秒步包含 8 个子步；高分段、低迭代设置会自动增加子步数：

```text
substeps = ceil(dt × 960 × max(1, segments/64) × max(1, sqrt(36/iterations)))
h = dt / substeps
damping = 0.99^(120 × h)
velocity = (x - x_prev) × damping × h/previous_h
x_prev = x
x = x + velocity + acceleration × h²
```

首个子步没有历史步长时，`h/previous_h` 取 1。重置会清除历史步长。阻尼按时间换算，并在外部步长或迭代滑块变化时换算历史位移，避免子步数量变化引入额外速度。

相邻节点由可断开的连接 `RopeLink` 关联。若连接当前长度为 `d`，静止长度为 `L`，则沿连接方向施加位置修正。两个节点都可运动时各分担一半；固定或正在拖拽的节点权重为零，另一端承担全部修正。每个子步重复滑块指定的轮数，正反交替遍历以减小方向偏差。

每轮约束后，将自由节点限制到世界边界和地面上方。启用圆形障碍物时，若节点进入 `圆半径 + 节点半径` 范围，就沿圆心到节点方向投影到圆外。碰撞和约束交替求解。

剪断不是仅隐藏一条线：将最近连接的 `Active` 设为 `false`，该连接同时从求解器和渲染中移除，断口两侧可独立运动。重置重新建立原始拓扑。

拖动前，沿两个方向累计有效连接的静止长度，遇到首个固定锚点或断口就停止。目标位置不能超出到达这些锚点所需的长度；双端固定时投影到两个可达圆盘的交集，避免鼠标把总长 1000 的绳子拉成 1300 多。单端固定和移动锚点分别使用各自连通绳段的长度限制；剪断会解除断口另一侧锚点施加的限制。

拖动固定节点会更新其 `Anchor`。拖动自由节点期间临时令其约束权重为零，并同步 `Previous`，释放后恢复自由运动。鼠标位移会先在连通绳段内进行额外几何约束投影，同时给其他节点的 `Previous` 加上相同修正，保留其已有速度，避免把几何编辑变成松手时的巨大弹簧冲量。断开的其他绳段不参与该次拖动投影。障碍物的中心仍可直接拖动。

这是迭代位置约束模型，仍有有限求解误差。可达圆盘限制依据绳长，不做绕障碍物的最短路径规划；人为把障碍物移到锚点或绳子必须经过的位置仍可能形成互相冲突的约束。具体误差测量见 `ROPE_STIFFNESS.md`。

## 粒子：固定容量池 + 半隐式 Euler

实现：`src/PhysicsLab.Core/ParticleSimulation.cs`。

每个粒子保存位置、速度、寿命、年龄、尺寸、颜色参数和类型。一个容量 10,000 的预分配数组保存活动粒子，活动区为 `[0, Count)`。删除粒子时将最后一个活动粒子交换到删除位置，然后递减 `Count`，无需平移数组。新发射检查容量上限。

普通发射用小数累加器积分发射速率：

```text
emissionDebt += particlesPerSecond × dt
spawnCount = floor(emissionDebt)
emissionDebt -= spawnCount
```

运动更新：

```text
velocity += force × dt
position += velocity × dt
age += dt
```

寿命到期或远离场景的粒子回收。倒序遍历保证交换删除不会跳过待处理的原有粒子，也不会在当前步重复处理新产生的烟花火花。随机数固定种子为 2026，重置后可复现同一序列。

- **喷泉**：向上扇形速度、风力和向下重力，地面反弹系数 0.48，水平速度碰撞衰减 0.84。
- **烟花**：按频率发射火箭，火箭寿命结束时生成 130 个向外扩散的火花；点击爆发生成 180 个火花。火花有额外速度阻尼。
- **飘雪**：顶边随机发射、弱重力、横向正弦扰动，越过水平边界后环绕。寿命为用户参数的 5 倍。
- **旋涡**：相对可移动中心计算法向量，施加向心、切向加速度和速度阻尼。重力参数映射为向心力强度。

## 绘制

`SimulationCanvas` 将固定的 1200×760 世界按窗口可用区域等比缩放，保持圆形与绳索比例。`System.Drawing` 双缓冲绘制静态环境、连线、锚点、节点和粒子。粒子按年龄分档淡出；画笔与画刷预先缓存，避免每个粒子每帧分配 GDI 对象。关闭窗口时释放资源。

界面参数通过事件直接修改核心模型；暂停只停止物理步进，仍可拖拽、剪断或产生粒子。`N` 在暂停状态下只推进一个固定步长。
